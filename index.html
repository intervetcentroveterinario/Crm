Configurar Sincronização

Para funcionar em vários computadores, conecte ao Firebase.

  1. Acesse firebase.google.com → crie um projeto
  2. Vá em Realtime Database → Criar banco → Modo de teste
  3. Copie a URL do banco (ex: https://seu-projeto-default-rtdb.firebaseio.com)
  4. Cole abaixo e clique em Conectar

Configure com a mesma URL em cada computador da clínica.
